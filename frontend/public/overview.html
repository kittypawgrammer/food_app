export interface Project {
  id: string;

  title: string;
  tagline: string;
  description: string;
  category: "Fullstack" | "Frontend" 
          | "Backend" | "AI & Tools";
  tags: string[];

  featured: boolean;
  publishedAt: string;
}

How Data Flows in Next.js 16

1

Server Execution (Zero Client JS)

getProjects() runs inside app/projects/page.tsx on the server during request or static build.

2

Client Hydration Boundary

Data is passed as props to ProjectListFilter ('use client') for instant search and category filtering.

3

Async Dynamic Routing

Clicking a card navigates to /projects/[slug] where Next.js 16 awaits route params: await params.
